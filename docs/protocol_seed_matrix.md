# Protocol — the 8x8 policy-seed by state-seed matrix

Frozen and committed **before** any matrix entry was computed, so the summaries below
cannot have been chosen after seeing the result. Append-only. Extends
`docs/protocol_width_populations.md` (commit `2cb7ab7`), whose definitions of
matched-state scale, occupancy-weighted own scale and PROXY apply unchanged.

## Scope

Tasks: Walker, G1, LEAP. Cells: `PW_ent` and `WML_noent` only. Seeds 301-308.

For each algorithm **separately**:

```
M[i, j] = median pre-tanh sigma produced by policy seed i
          on the states generated by seed j of the SAME algorithm
```

Each task therefore yields one 8x8 PW matrix and one 8x8 WML matrix. Rows are policy
seeds, columns are state seeds, both in the order 301, 302, ..., 308.

No new state banks are generated. The existing hash-verified per-seed subsets of the
canonical banks are used, selected by the `source` label, pooling exactly the depths each
bank already contains — Walker and G1 50/150/300/500/700/900, LEAP 50/100/200/300/400/480.

**Seed order is fixed at 301-308 and is never reordered by magnitude and never clustered**,
in any table or figure.

## Sample-size check, reported before any matrix

Each bank holds 32 states per (arm, seed, depth) over 6 depths, so every per-seed subset
should contain **192** states, making all 64 entries of a matrix equal-sized, diagonal and
off-diagonal alike.

This is stated as an expectation to be **verified, not assumed**. The check is reported
before any matrix, because the Walker WML diagonal of 0.218 against a pooled sibling value
of 9.12 is a 42x gap in a median, and if the diagonal rested on fewer states some of that
could be a sampling artifact rather than a property of the policies.

If any counts are unequal, every affected entry is recomputed on a subsample of the
smaller count, drawn with a fixed documented seed, and **both** the full and the subsampled
versions are reported.

## The six summaries, frozen now

Fixed before computing. Computed per task, per algorithm.

1. **diagonal median** — `median_i M[i, i]`
2. **off-diagonal median** — `median_{i != j} M[i, j]`
3. **per-policy sibling amplification** — `A_i = median_{j != i} M[i, j] / M[i, i]`,
   one value per policy seed
4. **task-level amplification** — `median_i A_i`
5. **fraction of off-diagonal entries exceeding their own diagonal** — over all ordered
   pairs `i != j`, the fraction with `M[i, j] > M[i, i]`, i.e. compared against the
   diagonal of the same **row**
6. **row-wise dispersion on log sigma** — statistic chosen and documented here before any
   matrix is seen: for each row `i`, the interquartile range of `log10 M[i, j]` over the
   eight `j`, reported as the median of that IQR over rows. Chosen because it is
   scale-free, insensitive to the single extreme entries these distributions carry, and
   defined identically for PW and WML.

## PW is the control, measured not asserted

PW is **not** described as "flat". Its `A_i` is computed by the identical procedure and
reported next to WML's, per task, so the contrast is a measured quantity.

The relevant existing PW figures for reference: PW neutral-versus-own ratios on Walker are
0.94 to 1.02, and in the seed split PW rows sat within 1.1x everywhere except LEAP's PW
half at 2.67x. Whether PW's `A_i` is near 1 is a question this matrix answers, not an
assumption it starts from.

## Figures, conventions fixed now

* One heatmap per task per algorithm: six heatmaps in total.
* **Colour scale is log10 of the matrix entry, shared between PW and WML within a task**,
  with common `vmin`/`vmax` taken from the union of that task's two matrices, so the two
  panels are directly comparable. Not shared across tasks, since the tasks differ in
  absolute scale by more than a decade.
* Axes labelled with seeds 301-308 in that order, rows = policy seed, columns = state seed.
* One compact figure of per-seed `A_i` with PW and WML together, per task.

## Stage 2 secondary quantities

For every matrix entry, on the same policy/state pair, also compute median `|mu|`, `sat95`
and `sat99`, under the saturation definition already frozen in
`docs/protocol_width_populations.md`. These are **secondary**. They address whether large
sibling-state sigma arrives together with larger means and saturation or is confined to the
variance head. Any association reported is descriptive; no causal reading is offered.

## Reporting rules

* If the matrix is heterogeneous, or driven by a few seed pairs rather than a general
  pattern, that is stated plainly. A low-diagonal / high-off-diagonal story is not forced.
* No causal mechanism is claimed. The terms "OOD", "pinned by data" and "critic error
  causes this" are not used.
* Occupancy overlap between seeds is **not** measured by this design, so no claim is made
  that seeds converge to different regions. What is measured is sigma evaluated on
  different state sets.
