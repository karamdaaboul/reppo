# Protocol — width populations and what each one measures

Frozen before the accompanying measurements were computed. Committed ahead of the
analysis so the ordering is auditable. Append-only.

Policy width here always means the **pre-tanh** scale `sigma_theta(s)`, the scale
parameter of the Gaussian before the tanh squash, as returned by
`scripts/load_ckpt.py:policy_dist` after observation normalisation.

## The two populations

### MATCHED-STATE SCALE

Two policies evaluated on the **exact same states**. Isolates the learned
state-conditional mapping `s -> sigma_theta(s)` over whatever population those states
represent.

It does **not** measure the exploration scale a policy experienced during training. A
matched-state comparison on states neither policy visits is still a valid matched-state
comparison of the scale function; it is simply a statement about the function on that
domain, not about either policy's behaviour in its own operation.

A matched-state ratio is well defined for any state set, including a set that is
off-distribution for one or both policies. The domain must be named whenever the ratio
is quoted.

### OCCUPANCY-WEIGHTED OWN SCALE

Each policy evaluated on states generated by **itself**. This combines two distinct
things: the state-conditional scale function, and the state visitation the policy
induces.

A ratio of the form

```
sigma_WML( s ~ d_WML )  /  sigma_PW( s ~ d_PW )
```

is **not** a same-state operator comparison. The numerator and denominator are evaluated
on different state distributions, so the ratio confounds a difference in the scale
function with a difference in where each policy goes. It answers "how wide is the
behaviour each arm actually produces", which is a legitimate question and a different one.

### PROXY

The `on-arm` figures previously reported for the cells `PW_noent` and `WML_ent` are **not**
states those cells visit. Each bank was built from its task's two baseline runs, so its
`source` labels come from `PW_ent` and `WML_noent` only. For the two newer cells the
so-called on-arm column is the **same-arm baseline** states.

From this document onward those figures are labelled **PROXY** and are never called
on-policy, on-arm, or own-distribution. A PROXY column carries the assumption that a cell
shares its baseline's visitation, which is precisely the assumption under scrutiny, so it
is not evidence for or against an occupancy claim.

## Neither population is designated the true width

No population is declared correct here, and no primary outcome already frozen elsewhere is
redefined. The two answer different questions:

* a claim about **the operators compared on common ground** — matched states, visitation
  held fixed — is a matched-state claim;
* a claim about **the policies as deployed** — the width of the behaviour each arm
  produces — is an occupancy-weighted claim.

Both are reported. Whenever a width ratio is quoted anywhere downstream, the population it
was computed on is named in the same sentence. A number without a named population is not
a usable result.

## Conventions carried in unchanged

* **Ratio convention.** Median over seeds of per-seed log ratios, exponentiated. Never a
  mean of ratios. Because the median commutes with monotone transforms this equals the
  median of the per-seed ratios exactly.
* **Saturation.** `P(|a| > t)` per **action coordinate**, computed exactly from the
  pre-tanh Gaussian via `P(|tanh Y| > t) = Phi((-c-mu)/s) + 1 - Phi((c-mu)/s)` with
  `c = atanh(t)`; the policy is not sampled. Averaged over states and coordinates.
* **Seeds.** 301-308 throughout.
* The canonical neutral banks are **not** discarded. An off-distribution fixed bank
  remains a valid matched-state comparison provided it is described as one.
